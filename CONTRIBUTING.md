# Как добавить файл

Репозиторий публичный: ссылка открывает его кому угодно. Чтобы **положить файл**, нужен бесплатный аккаунт GitHub.

## Самый простой путь

1. Открой https://github.com/vakumchik/tbankvzlom/upload/main/uploads
2. Войди в GitHub, если попросит.
3. Если GitHub предлагает Fork — нажми Fork.
4. Перетащи файл и сделай Commit → Create pull request.

Пул-реквесты, которые **только добавляют файлы в `uploads/`**, принимает бот.

## Что нельзя

- Менять `.github/`, workflows, README
- Класть файлы вне `uploads/`
- Пароли, токены, персональные данные третьих лиц
